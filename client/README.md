# Unity client

Open: `gAAAcha/client/Unity/gatcha1/`  
Server: `cd server && npm run dev` then **Play**.

## Controls

| Input | Action |
|-------|--------|
| WASD | Smooth tile move |
| Tab | Cycle lock-on |
| 1 / 2 / 3 | slash / shot / mend |
| Q | Dash (facing) |
| E | Stun Bolt |
| R | Ember DoT |
| F | War Cry (atk buff) |
| Z X C V B N | Equip 6 weapons |
| G / T | 1-pull / 10-pull |

## Expect

- Soft movement + camera only at screen edge
- Map 36×20, enemies: Slime, Ember Imp, Gust Wisp, Stone Brute
- HUD shows weapon, HP/MP, pity
